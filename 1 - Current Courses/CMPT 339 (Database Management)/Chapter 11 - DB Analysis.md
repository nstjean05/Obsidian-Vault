# 11.1 - When Are Fact Finding Techniques Used?
- Fact finding is crucial to the early stages of the development lifecycle
- Fact finding is the process of collecting terminology, system requirements, and data constraints before building
- Too much fact finding can lead to paralysis by analysis
# 11.2 - What Facts Are Collected
- Stages of DB System Development Lifecycle
	1. Database planning
	2. System Definition
	3. Requirements Collection and Analysis
	4. Database Design
	5. Application Design
	6. DBMS Selection
	7. Prototyping
	8. Implementation
	9. Data Conversion and Loading
	10. Testing
	11. Operational Maintenance
- At each of these stages, various types of data is captured, and documentation produced
# 11.3 - Fact Finding Techniques
- Five commonly used techniques:
	1. Examining Documentation
	2. Interviewing
	3. Observing the enterprise in operation
	4. Research
	5. Questionnaires
#### Examining Documentation
- How did the database arise?
- Information from the enterprise on the problem
#### Interviewing
- Most commonly used and useful technique
- **Pros**
	- Interviewees feel like part of the project
	- Interviewee gets free response to questions
	- Interviewer can adapt questions during interview
	- Body language
- **Cons**
	- Time consuming and costly
	- Success is dependent on communication skills
	- Dependent on willingness of participation
- **Unstructured**
	- General objective in mind
	- Dependent on interviewee for direction
- **Structured**
	- Better suited for DB design
